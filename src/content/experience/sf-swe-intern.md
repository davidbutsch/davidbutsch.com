While working at State Farm I utilizied AWS ARC to implement region switch workflows for multi-team failover scenarios. We mapped out existing system infrastructure, wrote custom execution blocks, and wired the components together for automated recovery orchestration.

We had the chance to demonstrate this capability by executing a failover within a breakfix environment.

I made use of Terraform to build out the plans, and integrated with GitLab CI/CD for automated deployment.

I also completed my [AWS Certified Cloud Practitioner](https://www.credly.com/badges/5430f2bc-8a4c-4e46-9587-123d5da7b86f) certificate while at State Farm.
